# Cat Diary

猫の日常を写真付きで記録できるWebアプリケーションです。

## URL

https://catdiary.xsrv.jp/diaries

## 概要

猫との日常を写真付きで記録・管理するために作成したアプリです。

Laravelを使用し、投稿の作成・編集・削除や画像アップロード機能を実装しています。

## 主な機能

* 日記投稿機能
* 日記一覧表示
* 日記詳細表示
* 日記編集機能
* 日記削除機能
* 画像アップロード機能
* バリデーション機能
